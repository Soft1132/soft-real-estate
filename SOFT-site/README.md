# SOFT — Real Estate Reels

A responsive portfolio for real estate agents developing their social presence. Includes English and Russian versions, four alternating reel slots, an email CTA and a circular vector favicon.

## Run locally

Open `index.html`, or serve this directory with:

```sh
python -m http.server 8080
```

## Add your reels

Edit `reels.js` and replace each empty `src` with a local MP4 path or a video URL. Videos load on demand and use native playback controls. The labeled concept previews remain until a video is added.

## Publish

This is a static site. Publish the repository root with any static hosting provider; no build command or package installation is required.
